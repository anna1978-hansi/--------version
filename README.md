# 面试复盘工具

这是一个帮助个人做面试复盘的本地工具。

它的目标是把一整场面试的原始内容整理成可回看的问答目录，再结合 AI 做基础分析，方便后续复盘、筛选重点问题、手动修正识别错误的轮次。

## 主要功能

- 支持输入完整面试内容：
  - 音频
  - 文本对话
- 将原始内容整理成“面试官 / 面试者”轮次结构
- 将轮次数据存入本地 SQLite
- 提供前端页面查看目录、问答详情和 AI 诊断
- 支持人工修正识别结果：
  - 合并两轮
  - 删除一轮

## 输入说明

### 1. 音频输入

如果输入的是完整面试音频，需要先将音频转成文本。

当前建议使用 Whisper 进行转写。

说明：

- Whisper 相关流程后续还会继续优化
- 目前更稳定的方式仍然是先拿到转写文本，再进入后续整理和分析流程

### 2. 文本输入

如果已经有面试文本，可以直接使用文本文件作为输入，交给脚本做轮次整理和入库。

## AI 分析

系统会调用 LLM 对对话内容做结构化整理和基础分析。

因此在使用前，需要配置你自己的 API Key。

例如：

- DeepSeek API Key
- 后续也可以切换到其他兼容模型

## 当前项目包含

- `deepseek-test.js`
  - 调用模型整理面试文本
- `backend-server.js`
  - 本地后端接口
- `backend/interview-store.js`
  - SQLite 数据存储与轮次处理
- `frontend/`
  - React 前端页面

## 启动方式

项目根目录下运行：

```bash
npm run backend
```

```bash
npm run frontend:dev
```

## 适合的使用场景

- 个人面试复盘
- 校招 / 实习面试问答整理
- 对长文本对话做目录化查看
- 对 AI 自动识别结果进行人工校正后再复盘
