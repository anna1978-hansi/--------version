第5轮  
面试官：好的。然后还有看到下面有写到，高频交互场景中，对 Animated 的新机制的这一块，问题发现和去优化。想了解一下，你觉得为什么 Animated 的性能比普通的 React 状态驱动动画会更好呢？  
面试者：因为……我想一下。

第6轮  
面试者：因为你 React 的普通……就是普通的状态驱动是说，就是你用一个 state，然后就是你后面去进行一个滚动的状态判断，然后对这个状态更新。然后因为它这个普通的 React 的状态，就相当于是它是在一个主线程里面执行的。Animated 就相当于是它把这个任务交给了就是你这个容器的原生线程嘛。因为你 RN 开发的时候，因为你用 RN 写的，它都是在就相当于是一个 JS 线程，后面是要把这个 UI 状态发给原生线程，然后这个原生线程才能去做处理的。你用 Animated 的话，相当于是你这个线程放到了它一个 Native 线程，然后这个时候相当于是这个线程不用去跑很复杂的 JS 代码，所以它执行起来就比较快，性能上面就好。  
面试官：好的，我看一下。
